# SpaceHero — Dark Mode Redesign

Production-ready React redesign of [SpaceHero](https://spacehero.in/) — Delhi-NCR valet parking, event doorman (Darbar), and professional driver hire.

## Stack

- React + Vite + TypeScript
- Tailwind CSS v4
- Framer Motion
- Lucide React
- React Router

## Run

```bash
npm install
npm run dev
```

```bash
npm run build
npm run preview
```

## Notes

- All copy, stats, forms, team bios, testimonials, and locations are sourced from spacehero.in.
- Images are loaded from `https://spacehero.in/images/...` (native assets).
- Mobile sticky bottom bar and desktop services dropdown are included.
- Booking center combines Drive Me, Monthly Driver, Driver Partner, and Contact forms.
